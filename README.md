# FAMBF — Клиентский калькулятор: защита капитала в USDT + участие в росте BTC

Брендированный калькулятор для разговора с клиентом. Один самодостаточный файл `index.html` — без сборки, без зависимостей, без бэкенда; открывается в любом браузере и работает на GitHub Pages. Считает на **реальных котировках опционов Deribit на 20.07.2026** (спот BTC $64 500, DVOL≈38, серии BTC-28AUG26 / 25SEP26 / 25DEC26) — котировки правятся прямо на странице.

Рядом лежит `calculator_advanced.html` — прежняя «инженерная» версия со всеми параметрами (волатильность, кэп/call-spread, произвольная защита), для внутренней работы.

## Как устроен (три шага клиента)

1. **Взнос** — сумма в USDT (по умолчанию 80 000; есть быстрые кнопки 10–250 тыс.).
2. **Срок × риск** — матрица: срок **~30 / ~90 / ~180 дней** (фактические серии Deribit BTC-28AUG26 · 39 дн, BTC-25SEP26 · 67 дн, BTC-25DEC26 · 158 дн) на допустимую просадку клиента **−2% / −3% / −5%** (защита 98/97/95%). В каждой ячейке — участие клиента в росте BTC при текущем распределении доходности и максимум по бюджету.
3. **Распределение доходности** — шкала **20–80%**: какая доля опционного бюджета идёт клиенту в участие, а какая остаётся проекту как **фиксированная маржа** (не зависит от BTC).

Дальше страница показывает: участие, максимальную просадку, маржу проекта (USDT, % за период и в годовых), резерв в надёжную ногу, котировку колла выбранной серии, таблицу «риск → доходность» (доход клиента при BTC +10/+30/+50%), график выплаты и сценарии −50%…+100% в USDT для введённого взноса.

**Живые котировки.** В блоке «Допущения» поля с марками ATM-коллов (5,20 / 7,25 / 11,95% от спота на 20.07.2026, калибровка по DVOL) и **днями до экспирации каждой серии** — оба редактируются, поэтому страница не устаревает: когда серия истекает, впишите новую (её дни и марку) — перед сделкой впишите mark price серии из терминала Deribit, всё пересчитается. Там же правятся спот, доходность USDT, буфер исполнения и комиссия входа.

## Как опубликовать на GitHub Pages

1. Создайте репозиторий и загрузите в него `index.html` (и при желании этот `README.md`).
2. **Settings → Pages → Build and deployment → Source: Deploy from a branch.**
3. Выберите ветку `main` и папку `/ (root)`, нажмите **Save**.
4. Через минуту страница будет доступна по адресу `https://<ваш-логин>.github.io/<репозиторий>/`.
5. Эту ссылку можно передавать заказчикам — всё считается у них в браузере, ничего никуда не отправляется.

Альтернативно файл можно просто открыть локально (двойной клик) или разместить на любом статическом хостинге (Netlify, Cloudflare Pages, Vercel).

## Важно

Инструмент для оценки структуры продукта — **не котировка и не инвестиционная рекомендация**. Проценты участия зависят от рыночной волатильности и ставок на дату запуска и **не являются обещанием доходности**. Защита тела действует только на дату погашения и обеспечивается надёжной ногой и купленными опционами; её надёжность ограничена платёжеспособностью контрагентов и биржи, а также устойчивостью USDT. Любое предложение с обещанием возврата капитала может быть регулируемым продуктом — перед запуском требуется юридическая проверка лицензирования в соответствующей юрисдикции.
